# Feature Specifications

## Overview
This document outlines the planned features for the Student Loan Decision App.

## Core Features

### 1. User Segmentation
- **New Students Path**: For students considering taking loans
- **Graduated Path**: For students already with loans, considering repayment

### 2. Loan Calculator
- Input student/parent financial information
- Calculate loan amounts needed
- Display monthly repayment estimates
- Show lifetime cost calculations

### 3. Scenario Comparison
- Compare "Take Loan" vs "No Loan" scenarios
- Visualize financial impacts
- Show different repayment timelines

### 4. Interest & Repayment Analysis
- Calculate interest accrual over time
- Show different repayment strategies
- Display tax implications (if applicable)

### 5. Financial Projections
- Income-based projections
- Cost of living considerations
- Career progression impact

### 6. Educational Resources
- UK student loan system explanation
- Repayment term conditions
- Government policy information
